# 双周期现货趋势策略 V2

研发日期：2026-10-19。只做BTC/USDT与ETH/USDT现货，无杠杆、无做空。

## 规则

Freqtrade策略名：`DualHorizonTrendV2`。K线周期1h，预热600根。
买入须同时满足：收盘价高于480小时简单均线；120小时均线高于480小时均线；480小时均线高于48小时前；24小时均线高于72小时均线；24小时平均真实波幅/价格小于4%；成交量大于0。
离场：24小时均线跌破72小时均线且价格低于120小时均线，或价格低于480小时均线的98%；另设10%固定止损。
不要求均线刚交叉，在满足趋势条件时允许重新入场。信号收盘确认，下一根开盘成交。
初始10000USDT，最多2仓，99%资金按可用余额及剩余仓位分配。

## 如何选择与验证

首次回测前固定3个候选，规则及筛选准则留档于RESEARCH_V2_PLAN.md。
只按2024年钱包回撤<=35%的候选中净收益最高者选出V2，随后写入evidence/v2-selection.json，再测试2025年；未根据2025结果改参数。
2025数据事先存在，且已用于旧策略评估，不称为真正未知的前瞻样本。3候选筛选仍有选择偏差。
官方lookahead-analysis抽查30个信号，未检出前视偏差。官方recursive-analysis以600/1200/1800根比较，部分均线显示舍入级0.000%差异。
完整日志：evidence/v2-*.log。原生交易及钱包序列：user_data/backtest_results/v2-*。

## 结论与边界

这次历史比较中V2提高收益、降低钱包回撤，但2025下半年明显落后旧版，不是普遍更优的证明。
胜率不足30%，依靠较少数盈利趋势覆盖多数亏损，实际体验可能有长时间连续亏损；止损10%不能保证跳空时损失不超过10%。
只覆盖两个交易对、两年行情；未评估2026年新数据和持续模拟交易。未显式模拟滑点、点差、订单簿冲击，1小时K线不能还原小时内路径。
保持旧策略默认配置，新版本需显式选择。未启动模拟或实盘交易。
